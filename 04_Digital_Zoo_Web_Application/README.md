# Digital Zoo: Interactive Web Application

## Project Overview
The Digital Zoo is a fully functional, interactive multi-page web application built as part of my Web Application Development coursework. I was inspired by the concept of ethical wildlife education, so this platform was built to serve as a digital alternative to physical zoos that hold animals captive. It provides an immersive and engaging environment where users can explore wildlife, learn about different animal classes, and play a fun quiz to determine what animal they are.

## Key Features
* Dynamic DOM Manipulation: The Animal Classes page uses JavaScript to hide and display specific sections (Mammals, Amphibians, Birds) dynamically without reloading the page.
* Audio Integration: Integrated HTML5 `<audio>` elements that allow users to listen to real animal sounds directly within the browser.
* Interactive Quiz Engine: A custom built personality quiz that calculates a user's score based on their selections using JavaScript logic to reveal their inner animal.
* Advanced Form Validation: The Sign-Up page features custom client-side validation using JavaScript Regular Expressions to ensure names and usernames contain only letters, and to enforce strong password creation.
* Responsive UI Design: Built with CSS Grid, Flexbox, and media queries to ensure the image galleries and forms adapt seamlessly to different screen sizes.
* Interactive Aesthetics: Implemented hover effects, animated GIF backgrounds, and custom Google Fonts to create a fun, engaging user experience.
