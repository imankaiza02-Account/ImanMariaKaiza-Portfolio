# In-Kind Donations Inventory Management System (DIMS)

## Project Overview
DIMS is a web-based inventory management system designed to manage in-kind donations for local community donation centres. It was developed to shift operations from manual, paper-based systems to a centralised, digitalised, and automated solution.

## The Problem
Many local community donation centres are operating with inadequate inventory management systems of in-kind donations, which result in ineffective and inefficient resource distribution. This problem originates from using tracking and management methods that are outdated, error-prone, and unsecure such as spreadsheets, paper-based systems, and manual operation and procurement processes. These operations often lack standardisation, have poor visibility, and lack management of unsolicited in-kind donations as current management practices aren't properly designed to govern diverse inventory, resulting in significant delays of aid that affect multiple parties including the organisation and staff, donors, and the recipients of aid.

## The Solution
To address these gaps, this project aimed to develop a centralised, cost-effective, and easy-to-navigate system that ensured transparency and traceability throughout an item's lifecycle. Using the Agile-Scrum methodology with HTML, JavaScript, CSS, PHP, and MySQL stack to develop the fully functional system that consisted of donor, staff, and admin modules, each having the ability to make and track donations, manage inventory with QR codes, and manage users, respectively.

## Key Features (System Modules)
* Donor Module: Provides donors with information on critical items needed by the centres. It has a donation form that donors can complete with information about the donations they will make. It allows them to track their donations and the stage at which they are at. It provides them with simple, system-generated reports and lets them submit feedback on the operations.
* Staff Module: Provides real-time stock visibility, allowing staff to upload information on critical understocked items that are needed. They can update the donation status of donors with the stage at which their donations are at. Additionally, it enables them to manage inventory using generation of QR codes during intake and scanning QR codes when distributing.
* Admin Module: Allows administrators to manage and oversee the entire system's functionality, operations, performance, and its users. They can generate reports on the inventory or of users in the system.

## Technical Stack
* Frontend: HTML, CSS, Javascript
* Backend: PHP
* Database: MySQL (hosted on XAMPP)
* Other Tools: PHP QR Code Library, FPDF (for report generation), EmailJS (for email verification).
